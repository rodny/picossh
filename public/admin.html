SSH connections

Unused (zombie) connections are ones no page is using: no terminal is attached, no transfer is running and nothing touched them for the unused-connection time (a minute unless changed under Server settings). They close when the background time their shells got runs out, unless it is Forever: those stay until closed here, picossh restarts or the SSH server drops them. Closing one ends its shells.

Replay buffers

Each shell keeps its latest output so a page that comes back can repaint its screen. While no page is attached, what the shell prints fills this buffer; once more than the limit has come out since the page left, the oldest of it is gone, and the page is told output was lost when it returns.
